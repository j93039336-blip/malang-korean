# 말랑 한국어 · Malang Korean

一个以**听说和阅读**为主的韩语练习网站，内容按《延世韩国语》第一册（延世大学韩国语学堂）组织：
全书 10 课，每课 4 个小节（共 40 节）。

🔗 打开 `index.html` 即可使用，整站就是**一个文件**，没有其他依赖。

## 功能

- **💬 句子**：按「课时 → 小节」筛选，点句子范读、点词弹出气泡讲解（词义 + 语法拆解），听写模式
- **📚 词汇**：449 个词按小节归类，点词范读，右侧拓展栏（来源、相关词、同义词、反义词、搭配、例句）
- **📐 语法**：77 个语法点按课时/小节组织，每点 5 句例句 + 针对训练
- **📝 题库 / 🎧 听力挑战 / 🃏 闪卡**：刷题检验与复习

## 使用说明

- 需要联网范读时会自动切换在线语音；也可以在首页切换范读模式
- 学习进度保存在浏览器本地（localStorage），换设备不会同步

## 更新网站

修改 `index.html` 后，重新上传到 GitHub 仓库覆盖同名文件即可，
GitHub Pages 会在 1~2 分钟内自动更新。
